# 音频示例

2026-11-10：使用用户指定预置音色的展示音频，36 条输出，共约 294.48 秒，于 2026-11-10 经用户确认发布。请求版本 2.8.1；24 kHz 单声道 PCM16 WAV，语速 1.0、音量参数 4.0。

| 案例 | 可播放输出 |
| --- | ---: |
| 普通话、英语音色延续 | 2 |
| 六种情绪，各自对应文案 | 6 |
| 副语言 AudioTag | 4 |
| 9 种外语与中英混合 | 10 |
| 地方方言 | 8 |
| 故事、生活播客 | 2 |
| SSML 拼读 | 1 |
| 客服、直播、博物馆导览 | 3 |

文件位于 `peach-20261110/`。详细时长和 SHA-256 见 [生成记录](GENERATION.md)，实际输入及请求设置见页面「文本与参数」。

所有外语请求均显式指定标签；中英混合使用 lang=zh。用户听审认为咳嗽未生效，已移除该项。“堵塞”拼读由中文引导语与 SSML sym 音素 d / u / du / s / e / se 分两次合成后拼接，间隔 120 ms；不是一次完整 SSML 请求的输出。自动文件检查不等于听感、标签生效或逐字准确率认证，仍需团队人工审核。

`language-nl.wav` 为荷兰语；`one-voice-en.wav` 和 `one-voice-zh.wav` 分别为同一预置音色的英语、普通话合成输出，不是参考录音。

本组使用预置音色，不以合成输出冒充原始参考录音。旧音频已从当前公开目录移除，本地仍留有备份。

## 后续替换

推荐从项目内的 `启动控制台.command` 打开可视化管理界面：上传 WAV → 核对文案与参数 → 保存 → 预览 → 发布。保存会生成当前 `CATALOGUE.json`；本文件及 `GENERATION.md` 保留 2026-11-10 发布批次的历史说明。隐藏条目不会删除已公开文件，彻底下架需移除资源并重新发布。

将获准公开的音频加入新的版本子目录，在 data.js 填写对应 src、实际输入 text、请求版本 model、设置 settings，并将 illustrative 设为 false。使用新路径避免播放器读取旧缓存；删除展示项时同步移除不再使用的公开音频。运行 node scripts/validate.mjs，人工核对后发布。凭证、内部请求日志和原始脚本不得放入公开目录。

本目录只供 GitHub 展示站使用，不改变 Hugging Face 静态预览的后端状态。
