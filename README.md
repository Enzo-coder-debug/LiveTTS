## 模型简介

**LiveTTS** 是京东 LiveTTS 团队从零训练的生成式文本转语音模型，面向自然、富有情感且可控的语音生成。模型支持短音频零样本音色克隆，并围绕多语种、中文方言、情感风格、语速和副语言表达构建统一的语音能力。

LiveTTS 的核心设计是**将音色与表达能力解耦**：同一个音色可以切换语种、方言、情绪与语速，减少为不同场景重复录制音色数据的成本，为对话交互和长篇内容提供可复用的声音基础。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **零样本音色克隆** | 使用约 3–15 秒参考人声进行音色克隆，支持保留韵律口音的增强推理与轻量声纹推理。 |
| **精品音色定制** | 基于约 30 分钟至 5 小时的授权录音进行 LoRA SFT，定制具有鲜明风格的音色。 |
| **多语种与方言** | 在同一音色下切换不同语言与中文方言，支持跨语种、跨方言表达。 |
| **情感与风格控制** | 通过指令控制温暖、高兴、悲伤、愤怒、恐惧等情绪，适配陪伴、客服、直播等表达风格。 |
| **语速与长篇表达** | 支持语速调节，以及面向播客、有声内容和直播的篇章级语音合成。 |
| **副语言表达** | 使用 `<laughter>`、`<sigh>`、`<throat>` 等 AudioTag 表达笑声、叹气与清嗓子。 |
| **中文拼读** | 通过 SSML 音素标签控制声母、韵母及音节拼读，面向语言教学等场景。 |

> 3–15 秒指参考录音的时长，并非合成耗时。具体能力、效果和接口可用性以接入的模型版本为准。

### 语言与方言

- **中文及外语**：中文、英语、德语、法语、西班牙语、日语、荷兰语、阿拉伯语、韩语、印尼语。
- **中文方言**：东北话、河南话、闽南话、天津话、四川话、陕西话、粤语、上海话、济南话、北京话。

## 听听 LiveTTS

前往 **[模型主页的效果展示](https://enzo-coder-debug.github.io/LiveTTS/#demo)**，试听不同语言、方言、情绪、语速以及长篇表达、中文拼读等示例，并查看对应文案与生成设置。

当前公开样音以预置音色为主，用于展示不同表达能力，**不等同于零样本克隆对照实验**。公开展示页提供预生成音频试听；在线 API 接入需另行联系团队。

[Speech Studio](https://enzo-coder-debug.github.io/LiveTTS/playground/) 提供独立的中英文语音体验界面预览。**目前仅部署前端，未接入模型 API；不生成语音，音频区域为空占位。** 接入真实生成需要另行部署保存密钥、实施鉴权与调用限额的后端。

## 应用场景

- **语音对话与情感陪伴**：为角色提供可控的音色、情绪与表达风格。
- **客服与智能外呼**：结合音色定制、语速和风格控制，构建业务语音交互。
- **数字人直播**：为讲解、导购和主播提供连续语音表达。
- **播客与有声内容**：用于长篇叙述、故事演绎和内容配音。
- **多语种与本地化**：复用同一音色生成不同语言、方言版本的内容。
- **教育与语言学习**：结合中文拼读能力制作发音和教学素材。

## 评测与模型说明

团队围绕发音准确性、流畅性、自然度、情感表达、音色保持及实际业务场景开展内部评测。相关结果与比较版本可在 [模型主页](https://enzo-coder-debug.github.io/LiveTTS/#eval) 查看，测试口径与局限见 [模型说明](livetts-github/MODEL_CARD.md)。

评测结果仅适用于对应版本与测试条件，不代表独立第三方榜单排名。

## API 接入与合作

LiveTTS 已提供 API，可联系团队申请技术评估与接入，讨论音色定制、多语种语音生成及业务集成。

欢迎通过 [GitHub Issues](https://github.com/Enzo-coder-debug/LiveTTS/issues) 留下使用场景和接入需求。请勿在公开 Issue 中提交 API 密钥、私人录音或其他敏感信息。

本仓库用于模型介绍与效果展示，**不包含模型权重**。模型、接口与音频的使用授权需与团队确认；音色克隆请仅使用已获授权的录音，不得用于冒充、欺诈或误导性内容。
